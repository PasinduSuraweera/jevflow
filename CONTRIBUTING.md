# Contributing

JevFlow is an early project. Check ROADMAP.md before proposing major changes.

1. Create a focused branch.
2. Keep code, documentation, and UI claims consistent.
3. Run `node --check dist/app.js` after JavaScript changes.
4. Test relevant scenarios, invalid JSON, keyboard controls, and narrow layouts.
5. Open a pull request describing the user-visible change and how it was checked.

Never commit API keys, private input data, or credentials. Keep model predictions clearly distinguished from local simulation. Keep visible copy free of em dashes.
